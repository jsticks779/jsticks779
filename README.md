## `~$ whoami`

I'm **Junior Jovin** — a full-stack engineer from **Tanzania 🇹🇿**, building software for the
problems I can actually see around me: shops that still track stock on paper, workers with no
credit history, laptops that can't share the Wi-Fi they're already on.

I work end to end — schema, API, UI, deploy — and I like the unglamorous parts: permission
systems, migrations, webhook signatures, and drivers that lie to you.
